# Capturas de la aplicación en Chromium

Capturas reales de la ejecución de `python3 tests/browser_smoke.py` durante la auditoría del 2026-10-13. No son diseños simulados. El navegador cargó la aplicación local bajo una subruta como la que utiliza GitHub Pages. Los valores mostrados corresponden al caso **sintético** de extrusión tubular de `tests/fixtures.js`, no a un material ni máquina real.
